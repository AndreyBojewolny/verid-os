# SKILL.md — VeridOS v2.5: контракт разработки

## Общие ограничения
- Язык: Rust 1.85+, no_std-совместимость ядра (минимум аллокаций; SmallVec/arrayvec).
- Криптография: только BLAKE3 (хеш и MAC), HKDF-BLAKE3 для вывода ключей.
- Сериализация: канонический CBOR, бит-в-бит детерминированный.
- Хранение: журнал в памяти (Vec) для прототипа; persistence — отдельный этап.
- Большие данные (>4 KB): в payload только BLAKE3-хеш, данные — в CAS-заглушку.

## Что запрещено
- Менять specs/ без согласования с Архитектором.
- Хранить ключи в структуре журнала или статических переменных.
- Использовать внешние хранилища в ядре.
- Выдавать «почти рабочие» решения: каждый brief требует 100% тестов.

## Критерии приёмки (Gate)
1. Сборка без предупреждений (cargo build --release).
2. Тесты проходят на hosted-таргете (для TASK-002: и на seL4-userland, побитно).
3. Мутационный тест: подмена 1 байта -> verify_chain обнаруживает.
4. Replay: state_hash совпадает с оригиналом.
5. Идемпотентность: повторная доставка события не меняет состояние.
6. Taint-наследование: OR флагов по цепочке.
7. Документация: комментарии с гарантиями у каждой публичной функции.
