# Конституция VeridOS — changelog v2.4 -> v2.5

## Новое в v2.5
1. Инвариант эволюции (конституционный уровень):
   «Эволюция не может расширять собственные права». Нарушение = CapabilityViolation.
2. Научный трек: ретроспективный reachability-анализ поверх верифицируемого журнала
   — вычисление overgrant surface, формального near-miss-расстояния и
   counterfactual-анализа гипотетических грантов.
   Отграничение: SkillGuard (runtime enforcement), Near-Miss (LLM-эмпирика),
   HarnessAudit (чек-лист по вручную аннотированным правилам), Bernstein (аудит).
3. Evolution Loop v0.2 включён в конституцию (все 5 открытых вопросов РЕШЕНЫ,
   см. specs/veridos_evolution_loop_spec_v0.2.md).
4. События журнала расширены с 16 до 21.
